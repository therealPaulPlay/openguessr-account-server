## What is OpenGuessr?

OpenGuessr is a free geography-guessing game available on openguessr.com. It's not open-source, but open for everyone to play for free and no game mode is locked behind a paywall.

## FAQ

Q: Can road names be hidden?
A: No, it's currently not possible with this inexpensive API setup that enables the game to be free.

Q: I received a warning or was banned, what should I do?
A: Please create a post in the mod-requests Discord forum

Q: I lost access to my account, what should I do? 
A: Please refer to the account-help channel on this server

Q: Multiplayer doesn't work for me. What should I try?
A: Ensure you are not using a VPN, ensure you aren't behind a firewall (e.g. Anti Virus incorrectly flagging OpenGuessr), and make sure to use a browser that doesn't
ship with a built-in proxy such as Opera. Moreover, don't use Brave Browser as it commonly messes with the WebSocket configuration.

## Features

**Special modes:** OpenGuessr features unique game modes such as Country Guessr, Image Guessr or Meta Guessr.

**Multiplayer:** The game features ranked, elo-based duels, 2v2 ("Team duels"), and custom rooms. There are also occasional tournaments accessible via the multiplayer page.
Additionally, there's a "public rooms" feature that allows players to open up a custom multiplayer room to everyone and to advertise it in the join section.

**Maps:** There are many official maps, such as the World map, Famous Places or Capital Cities. Additionally, there are official country and continent maps. Then there are thousands of community-made maps as well.

**Competitions:** Besides the daily competition, there are community-made competitions. This is effectively asynchronous multiplayer, where you can compete on a determined set of locations
and see your place on the leaderboard once it's over.

**Customization:** Players can unlock pins (the ones placed on the map to guess), badges, and more. The premium currency is Tokens, which players can gain through playing duels or tournaments as well. Moreover, player profiles feature an about section and a country flag.

**Polish:** OpenGuessr has handcrafted sound effects and illustrations to make the game feel premium. The UX is constantly being optimized to not only look consistent, but to also be 
intuitive to reduce friction.

**OpenGuessr Education:** A great learning platform for OpenGuessr. Includes guides on creating maps, how to get better etc. as well as quizzes to learn metas or countries. Available via education.openguessr.com.

**More:** The game is being continously updated and there may be features not included here. If you're not sure about a feature, advise players to check the subreddit or the announcements channel.
